## Purpose

This directory is the authoritative documentation library for PiratePDF and the BlackFlag Engine.

Repository Markdown files are the editable source of truth. Generated indexes, reports, websites, Word documents, and PDF manuals are derived publications.

## Documentation Principles

PiratePDF documentation shall be:

- Accurate.
- Searchable.
- Traceable.
- Version controlled.
- Consistent.
- Updated alongside implementation changes.
- Understandable to both current and future contributors.
