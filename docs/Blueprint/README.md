## Status Definitions

- **Approved:** Committed product or engineering requirement.
- **Draft:** Under active design.
- **Proposed:** Candidate requirement awaiting review.
- **Deferred:** Accepted concept not assigned to an active release.
- **Rejected:** Considered but intentionally excluded.
