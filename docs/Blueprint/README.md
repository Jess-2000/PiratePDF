## Purpose

The PiratePDF Master Blueprint is the authoritative high-level reference for the product vision, BlackFlag Engine architecture, application behavior, engineering standards, testing strategy, and long-term roadmap.

The Blueprint defines the intended system and product direction. Detailed implementation requirements belong in technical specifications and Architecture Decision Records.

## Authority and Scope

The Master Blueprint shall:

- Define the product vision and guiding principles.
- Define the major BlackFlag Engine and PiratePDF application boundaries.
- Describe the intended Standard and Professional edition strategy.
- Establish project-wide engineering and quality expectations.
- Provide long-term direction without replacing detailed subsystem specifications.

Conflicts between the Blueprint and a technical specification shall be reviewed and resolved explicitly.
